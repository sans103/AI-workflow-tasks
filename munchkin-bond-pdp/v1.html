How Bond is built

The borosilicate glass body

Does

The bonded silicone shell

Does
Fuses soft-touch silicone to the outside of the glass.
Helps

4 ounce suits newborn feeds, roughly 0 to 3 months. 8 ounce suits bigger feeds from around 3 months. Both take the same nipples and the same valve, so nothing else changes when you size up.
